# Engineering Calculator

A Python-based engineering calculator for electrical calculations and basic engineering tools.

## Current Features

- **Ohm's Law:** Calculate voltage, current, or resistance using the other two values.

## Ohm's Law

\[
V=IR
\]

Where:

| Symbol | Quantity | Unit |
|---|---|---|
| V | Voltage | Volts (V) |
| I | Current | Amperes (A) |
| R | Resistance | Ohms (Ω) |

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Run the program:

```bash
python ohms_law.py
```
